# PALADIN - Gym & Fitness App

> **Built by [Abdul Qudoos](https://www.abdul-qudoos.com)**, AI Automation & Forward Deployed Engineer · [Read the case study](https://www.abdul-qudoos.com/work/gym-paladin) · [More projects](https://www.abdul-qudoos.com/work)

A modern, sleek fitness/gym application built with Next.js 14, Tailwind CSS, and Framer Motion.

## Features

- 🎨 Modern, bold UI with gym-inspired design
- 🎬 Smooth animations and transitions
- 📱 Fully responsive mobile-first design
- ⚡ Built with Next.js 14 App Router
- 💅 Styled with Tailwind CSS
- 🎭 Animated with Framer Motion
- 🚀 Splash screen on load
- 🎯 Hover effects and interactive components

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build

```bash
npm run build
npm start
```
